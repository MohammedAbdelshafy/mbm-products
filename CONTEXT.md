# MBM Offers CONTEXT

One job: help visitors understand which existing service or tool fits their need and send them to the correct owner repo.

## Inputs
- Offers page: [index.html](index.html)
- Project summary: [README](README.md)
- Portfolio map: [Jarvis ICM](https://github.com/MohammedAbdelshafy/jarvis-mbm/blob/feature/icm-portfolio-map/ICM/REPO_MAP.md)

## Process
1. Describe each tool by its customer outcome.
2. Link to the canonical implementation; never create a duplicate here.
3. State sample/demo limitations and unverified price/checkout terms.
4. Keep product names consistent with the portfolio naming guide.
5. Validate links and current readiness before publishing a commercial claim.

## Output
A plain-language catalog that routes buyers to the existing product or service.

## Check
Every card links to the correct repo/page; no false claim that all products are production-ready, tested or paid.
